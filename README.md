# FinTech Labs IAM Modernization Project

## Project Overview

This project demonstrates the design, audit, and modernization of an
Identity and Access Management (IAM) framework for a fictional fintech
organisation, FinTech Labs Inc.

The project applies core IAM and Zero Trust security principles to a
cloud-based environment following a simulated security incident.

## Objectives

- Identify and classify human and non-human identities
- Apply Role-Based Access Control (RBAC)
- Implement the Principle of Least Privilege (PoLP)
- Apply Separation of Duties (SoD)
- Analyse AWS CloudTrail audit events
- Investigate potential IAM security incidents
- Design a Zero Trust security transition strategy

## Project Structure

- `part-01-identity-taxonomy` — Identity classification and risk analysis
- `part-02-access-control` — RBAC, least privilege and separation of duties
- `part-03-incident-investigation` — CloudTrail forensic analysis
- `part-04-zero-trust` — Zero Trust architecture and executive recommendation
